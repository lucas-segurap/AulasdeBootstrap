# 🎨 Aulas de Bootstrap

Este repositório foi criado para guardar os conteúdos, exercícios e projetos desenvolvidos durante as **aulas de Bootstrap**.

Durante as aulas, foram estudados conceitos de desenvolvimento web utilizando o Bootstrap, aprendendo a criar páginas mais organizadas, responsivas e com uma aparência mais profissional.

## 📚 Conteúdos estudados

* Introdução ao Bootstrap
* Instalação e utilização do framework
* Sistema de Grid
* Containers
* Botões
* Cards
* Navbar
* Formulários
* Tabelas
* Imagens
* Responsividade
* Classes de estilização
* Componentes do Bootstrap

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* Bootstrap
* Visual Studio Code
* Git e GitHub

## 🎯 Objetivo

O objetivo das aulas foi aprender a utilizar o **Bootstrap** para facilitar o desenvolvimento de páginas web, entendendo como seus componentes e classes podem ser utilizados para criar interfaces mais bonitas, organizadas e adaptáveis a diferentes tamanhos de tela.

## 🚀 Sobre o aprendizado

Durante as aulas, pude conhecer melhor o Bootstrap e entender como ele pode ajudar no desenvolvimento de sites. Os exercícios serviram para colocar em prática os conteúdos aprendidos e melhorar meus conhecimentos em desenvolvimento web.
